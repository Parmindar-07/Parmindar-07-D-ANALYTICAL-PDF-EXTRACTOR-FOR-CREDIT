1. SEMANTIC EXTRACTION
- Match labels by meaning, not exact text.
- Example:

- LABEL VALUE POSITION RULE:
  A label's value can appear in TWO ways in a PDF:
  A) SAME LINE (inline):
     Label: Value
     Example: "Business Name: ABC Corp"
     → Extract "ABC Corp" as the value.
  B) NEXT LINE (below):
     Business Name:
     ABC Corp
     → The line immediately below the label is its value.
  - Always check both positions before deciding value is missing.
  - If value is on same line after colon → use it.
  - If same line is empty after colon → look at next non-empty line as the value.

- dba_name = alternate/DBA if different

4. ADDRESS PARSING
- Address field = street only.
- Parse city/state/zip separately.

  92057 = Oceanside
  91040 = Santa Clarita
- Always output state as 2-letter US state code.
- If raw text has full state name, convert it:
  Florida -> FL
  California -> CA
  New York -> NY
- For US forms, prefer US address groups with 2-letter US state and 5-digit ZIP.
- Do not put Canadian province/postal code into business_state/business_zip.
- If state is ON and ZIP looks like L7C 3L8, leave US state/zip blank unless the form clearly asks for Canadian address.

For this pattern:

Do not mix WI with PO BOX CALEDON.
Do not mix ON with EAU CLAIRE.

- If an address has a US state code and 5 digit ZIP near it, keep that address with the same entity.
- Example:

  PO BOX 8 CALEDON EAST + CALEDON + ON + L7C 3L8 belong together.

BUSINESS VS OWNER ADDRESS:

6. TAX ID vs SSN (CRITICAL)
Business Tax ID:
- Labels:
  Tax ID, EIN, TIN, Federal Tax ID
- Priority 1 format:
  ##-####### is EIN.
  Example: 12-1234567 -> 121234567
- Priority 2 label fallback:
  If no ##-####### format is found, a nearby 9 digit number around EIN / Tax ID / TIN / Federal Tax ID labels is EIN.
- Priority 3 business fallback:
  If no label is clear, a 9 digit number near Business Name / Business Information / business detail can be EIN.
- Output format:
  9 digits only, remove hyphen/spaces.
- Example:
  330797819 -> 330797819
- Output key:
  business_info.ein_no

SSN:
- Labels:
  SSN, SSI Number, Social Security
- Priority 1 format:
  ###-##-#### is SSN.
  Example: 123-12-1234 -> 123-12-1234
- Priority 2 label fallback:
  If no ###-##-#### format is found, a nearby 9 digit number around SSN / SSI Number / Social Security labels is SSN.
- Owner SSN label rule:
  If a line says Owner SSN, SSN, SSN#, SSI Number, or Social Security, and the next nearby line is ###-##-####, always use that value as owners[].owner_ssn.
  Example:
    Owner SSN
    020-16-0115
  Output owner_ssn = 020-16-0115.

REJECT BAD TAX/SSN CANDIDATES:

- Also reject formatted versions of the same repeated number, such as 55-5555555 or 555-55-5555.
